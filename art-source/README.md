# Art source

`make_art.py` draws all of Taxi Time's art (the 6 `.tga` files in `TaxiTime\media\`) from shapes typed into the script. No outside or Blizzard art is used.

Run `python make_art.py` (plain Python 3, no extra packages). It writes the 6 files to `out\` next to the script. Copy them into `TaxiTime\media\` yourself. `python make_art.py all` also writes both design looks and preview pictures.
